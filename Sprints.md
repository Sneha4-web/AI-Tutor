# 🤖 BrainByte – 10 Sprint Development Plan

## Sprint 1 – Project Setup

- Create project repository
- Set up Python environment
- Install required libraries
- Set up Streamlit application
- Create basic UI
- Define project structure
- Create README documentation

---

## Sprint 2 – Student Profile

- Create student profile interface
- Accept student name
- Select class/level
- Select subject
- Select topic
- Select learning goal
- Select preferred explanation level

---

## Sprint 3 – Diagnostic Test

- Create initial diagnostic test
- Generate questions for selected topic
- Accept student answers
- Calculate diagnostic score
- Analyze basic/medium/weak concepts
- Store diagnostic performance

---

## Sprint 4 – AI Personal Tutor

- Connect AI API
- Design personalized AI prompt
- Generate lesson based on:
  - Subject
  - Topic
  - Student level
  - Diagnostic performance
  - Weak concepts
- Generate simple explanations
- Generate worked examples

---

## Sprint 5 – Adaptive Quiz System

- Create quiz interface
- Generate quiz questions
- Create Easy, Medium and Challenge levels
- Accept student answers
- Calculate score
- Display correct/incorrect answers
- Provide explanations for wrong answers

---

## Sprint 6 – Mistake Analysis

- Analyze incorrect answers
- Identify possible conceptual mistakes
- Generate personalized explanations
- Generate similar practice questions
- Allow student to retry questions
- Measure improvement after retry

---

## Sprint 7 – Database & Performance Tracking

- Set up SQLite database
- Create student table
- Create quiz attempts table
- Store:
  - Student
  - Subject
  - Topic
  - Score
  - Date
  - Attempt number
- Retrieve previous attempts
- Calculate average performance

---

## Sprint 8 – Weak Topic Detection

- Analyze previous quiz scores
- Identify low-performing topics
- Calculate topic mastery
- Create weak-topic detection logic
- Display strong and weak topics
- Generate personalized review recommendations

---

## Sprint 9 – Progress Dashboard & Learning Path

- Create student progress dashboard
- Display average score
- Display improvement
- Display completed topics
- Create performance charts
- Create personalized learning path
- Recommend the next topic
- Add review and retest functionality

---

## Sprint 10 – Integration, Testing & Finalization

- Connect Student Profile
- Connect Diagnostic Test
- Connect AI Tutor
- Connect Quiz System
- Connect Mistake Analysis
- Connect Database
- Connect Progress Dashboard
- Test complete learning cycle
- Test AI failures
- Test database storage
- Fix bugs
- Improve UI
- Prepare screenshots
- Prepare presentation
- Final demonstration

---
